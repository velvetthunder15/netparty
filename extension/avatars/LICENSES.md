# NetParty avatar artwork: licences and attribution

All 48 avatars in this folder (`av-*.webp` and `masters/av-*.png`) are derived from
**Microsoft Fluent Emoji** (3D style), https://github.com/microsoft/fluentui-emoji,
Copyright (c) Microsoft Corporation, released under the **MIT License** (full text below).

MIT permits use, modification and redistribution (including inside a commercial or store-published
browser extension) provided the copyright notice and permission notice are included. Ship this file
(or the MIT text below) with the extension, e.g. in the repo and in the packaged add-on.

Modifications made: trimmed transparent margins, some people emoji cropped to head/upper body,
re-centred on a transparent 256x256 canvas (masters) and resized to 128x128 WebP.
"Default" (yellow, non-realistic) skin tone used for all people, so no skin tone is implied.

Note: these are Microsoft's original emoji designs, not depictions of any copyrighted character.
